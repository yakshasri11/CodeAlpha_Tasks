# CodeAlpha Full Stack Development Internship Projects

This repository contains all the projects built during my **CodeAlpha Full Stack Development Internship**.

## 📁 Projects

---

### 🌐 1. Social Media Platform — Synvora

A full-stack futuristic social media platform combining features of Twitter/X and Instagram with an AI assistant.

**Features:**
- 🔐 JWT-based authentication (login/register)
- 📝 Create, like, and comment on posts
- 👥 Follow/unfollow users
- 🤖 AI assistant with multi-provider support (Anthropic, Gemini, Ollama)
- 📷 Live camera capture for posts
- 🕐 IST timestamps
- 📜 Terms & Conditions onboarding flow

**Tech Stack:** Node.js, Express, sql.js, Vanilla JS, JWT, HTML/CSS

---

### 🎥 2. MeetSpace — WebRTC Video Conferencing App

A real-time video conferencing application built with full peer-to-peer communication.

**Features:**
- 📹 Real-time video & audio calls using WebRTC + PeerJS
- 💬 Live group chat
- 🖥️ Screen sharing
- 🎨 Collaborative whiteboard with real-time sync
- 😄 Emoji reactions with floating animations
- ✋ Raise hand feature
- 👑 Host & co-admin moderation controls
- 🔒 Room-based sessions with join/leave notifications

**Tech Stack:** Node.js, Express, Socket.io, PeerJS, WebRTC, Vanilla JS

---

### 🛒 3. ShopNest — E-Commerce Web App

A full-stack e-commerce platform with separate buyer and seller roles, product management, and order processing.

**Features:**
- 🔐 User authentication (buyer/seller roles)
- 🛍️ Product listings with categories and search
- 🛒 Shopping cart and checkout flow
- 📦 Order management and tracking
- 🏪 Seller dashboard for product management
- ✅ Admin product approval system
- 💳 Address and payment info handling

**Tech Stack:** Django REST Framework, Python, SQLite, Vanilla JS, HTML/CSS
